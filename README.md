# 🎬 Movie Review Sentiment Analyzer

An end-to-end machine learning web application that predicts whether a movie
review expresses **Positive** or **Negative** sentiment, built on the IMDb
50K Movie Reviews dataset.

> Built as a Data Science / Machine Learning portfolio project — covers the
> full pipeline from raw text to a deployed, interactive web app.

---

## 📌 Problem Statement

Manually reading and labeling large volumes of movie reviews to gauge
audience reaction is slow and doesn't scale. This project trains a
classical NLP + Machine Learning model to automatically classify a review's
sentiment, and wraps it in a Streamlit app so anyone can try it interactively
or run it on a batch of reviews at once.

## 🎯 Objectives

- Clean and preprocess raw, noisy review text (HTML tags, punctuation, stopwords).
- Engineer TF-IDF features (unigrams + bigrams) without data leakage.
- Train and fairly compare three classical ML models.
- Select the best model objectively using F1-score.
- Ship a professional, usable Streamlit interface around the trained model.

## ✨ Features

- **Single review prediction** with sentiment label + confidence score.
- **CSV batch prediction** — upload many reviews, get a downloadable results file.
- **Model performance dashboard** — accuracy/precision/recall/F1 comparison table and charts.
- **Dataset statistics** — class balance, review length distribution, word clouds.
- Clean, modular codebase with training fully decoupled from the web app
  (the app only ever loads a saved model — it never retrains at startup).

## 📊 Dataset

**IMDb Dataset of 50K Movie Reviews** — a balanced dataset of 25,000 positive
and 25,000 negative movie reviews, commonly distributed as `IMDB Dataset.csv`
with two columns: `review` and `sentiment` (`positive` / `negative`).

Popular source: Kaggle — *"IMDB Dataset of 50K Movie Reviews"*
(`lakshmi25npathi/imdb-dataset-of-50k-movie-reviews`).

**Setup:** download `IMDB Dataset.csv` and place it at:

```
data/raw/IMDB Dataset.csv
```

## 🏗️ Architecture

```

      │
      ▼

      │

      │                        → evaluation via src/evaluate.py
      ▼
models/sentiment_model.pkl

      │
      ▼

      │
      ▼
app.py (Streamlit)          → loads saved artifacts, never retrains
```


## 🚀 Training Instructions

Run these from the project root, in order:

```bash
# 1. Clean and preprocess the raw dataset
python src/data_preprocessing.py

# 2. Generate EDA visualizations
python src/eda.py

# 3. Train, compare, and save the best model
python src/train.py
```

`train.py` prints a full comparison table and saves:
- `models/sentiment_model.pkl` — the best model by F1-score
- `models/tfidf_vectorizer.pkl` — the fitted TF-IDF vectorizer
- `reports/model_comparison.csv` — full metrics for all three models
- `reports/figures/model_comparison.png`, `confusion_matrix.png`
